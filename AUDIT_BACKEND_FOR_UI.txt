2) BOOKING CREATE — REQUIRED CHANGES
================================================================================
POST /api/booking/create
Auth: Required

NOW REQUIRED:
- fleet_id          (must be real active fleet from GET /api/fleet/get)
- terms_accepted    (must be true)

OPTIONAL:
- terms_version     (default "v1")
- base_amount, tax_amount, tolls_amount, waiting_amount
- amount, currency, passenger fields, etc. (same as before)

Example request:
{
  "service_type": "airport_transfer",
  "fleet_id": "FLEET_MONGO_ID",
  "pickup_location": "Riyadh Airport",
  "dropoff_location": "Hotel",
  "pickup_date": "2026-10-01",
  "pickup_time": "10:00",
  "dropoff_date": "2026-10-01",
  "dropoff_time": "12:00",
  "passengers_count": 2,
  "children_count": 0,
  "passenger_name": "Ali Khan",
  "passenger_email": "ali@email.com",
  "phone_number": "+96550000000",
  "payment_method": "card",
  "amount": 25,
  "base_amount": 20,
  "tax_amount": 3,
  "tolls_amount": 1,
  "waiting_amount": 1,
  "currency": "KWD",
  "terms_accepted": true,
  "terms_version": "v1"
}

If fleet_id missing or terms_accepted is not true -> backend returns 400.
